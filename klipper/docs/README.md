# Klipper's documentation

Valve Oil's Klipper doesn't ship upstream Klipper's documentation. This folder is here so Moonraker, which serves it to Fluidd as `docs`, finds it. Valve Oil's Klipper is built on upstream Klipper v0.14.0: read its documentation at [klipper3d.org](https://www.klipper3d.org/), or in [v0.14.0's `docs/`](https://github.com/Klipper3d/klipper/tree/v0.14.0/docs). What Valve Oil's Klipper changes is in Valve Oil's [`docs/klipper.md`](https://github.com/thelegendtubaguy/valve-oil/blob/main/docs/klipper.md).
