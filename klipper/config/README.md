# Klipper's example configs

Valve Oil's Klipper doesn't ship upstream Klipper's example printer and board configs. This folder is here so Moonraker, which serves it to Fluidd as `config_examples`, finds it. They're in [upstream Klipper v0.14.0's `config/`](https://github.com/Klipper3d/klipper/tree/v0.14.0/config). QIDI's printers use the configs in `~/printer_data/config`.
